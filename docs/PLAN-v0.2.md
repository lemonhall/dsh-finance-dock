## 契约：宿主持有面板状态（功能 5 的地基）

面板状态放宿主，客户端只是它的视图；这样**我能读、也能写**。存 `$DSH_HOME/dsh-finance-dock/state.json`（插件自己的目录，不污染 profile）。

```jsonc
{
  "selected": "^GSPC",          // 当前焦点
  "watchlist": ["^GSPC","AAPL"], // 用户自选（功能 7 以后用）
  "notes": { "AAPL": "我在看的" },// 我（agent）写给人看的标注
  "pinned": [],                  // 异动置顶（功能 3）
  "updatedAt": 1234567890,
  "revision": 7                  // 每次写 +1，客户端靠它判断要不要重画
}
```

路由：
- `GET  /dsh-finance/state` → 状态
- `POST /dsh-finance/state` → 合并写入（body 里给哪些键就改哪些），返回新状态 + revision
- 客户端**轮询** `state`（2s）而不是用事件 —— 宿主没有现成的推送通道，轮询够用且简单。

工具 `finance_panel`（宿主 `ctx.tools.register`）：
- `action: 'state'` → 读回来（我知道你在看什么）
- `action: 'select' | 'watch_add' | 'watch_remove' | 'note' | 'clear_note'` + `symbol` / `text`
- 我写完，面板 2 秒内自己跳过去（功能 5 的"我说 → 界面动"）。

## 功能 1：指标中文说明

静态表 `lib/glossary.js`（宿主发给客户端，或客户端内置）。每条 20–40 字，讲"是什么 + 为什么重要"，别写教科书。
例：`^TNX` = 美债10年收益率，全球资产定价的锚，它上去股票估值就压；`^VIX` = 标普期权的隐含波动率，俗称恐慌指数，20 以上说明市场在怕。

## 功能 2：风险偏好仪表（0–100）

四个输入，各自转成 0–1 后等权：
- `^VIX`：20 以下算平静（→1），35 以上算恐慌（→0），中间线性；
- `HYG`（高收益债）：**相对自身 1 个月走势**的位置（跌 = 信用紧张）；
- 铜金比 `HG=F/GC=F`：同样是相对自身 1 个月的位置（升 = 增长预期好）；
- `DX-Y.NYB`（美元指数）：走强 = 全球流动性收紧（→0.5 以下）。
读数 ≥65 标"风险偏好"，≤35 标"避险"，中间"中性"。**这是给人看的近似，不是可交易信号**，面板上要写明。

## 功能 3：异动置顶

`|changePct| ≥ 阈值`（默认 2%）的标的在列表顶部单独一组「⚠ 异动」。纯客户端计算，不需要宿主。

## 功能 4：多时区开盘倒计时

纽约（XNYS）/ 伦敦 / 东京 / 上海，各自的开收盘时间用**本地时区硬编码 + 夏令时近似**（北美 3 月第 2 个周日–11 月第 1 个周日、欧洲 3 月最后周日–10 月最后周日）。周末一律休市。
**这是近似**：不做节假日日历，面板上标"近似"。

## 功能 6：一键提问

DSH **没有**客户端"往会话里发一条消息"的服务（已列过：`layout/locale/sessions/slots/theme/timer/uiWorkspace/workspaces`，没有 chat/composer）。
所以实现为：把「标的 + 现价 + 涨跌 + 最新 3 条新闻标题」拼成一段提问 → **写进剪贴板** → 面板提示"已复制，去输入框粘贴"。
（同时把它记进宿主的 `pendingQuestion`，我调 `finance_panel state` 时也能看到。）

## 功能 13：中文/多源新闻

Yahoo 只有英文。加 **Google News RSS**：
`https://news.google.com/rss/search?q=<关键词>&hl=zh-CN&gl=CN&ceid=CN:zh-Hans`
- 免费、免 key、能走代理；返回 XML，用正则抠 `<item>`（不引 XML 库）；
- 面板上给个「源」切换：Yahoo（英文，个股准）/ Google 中文（宏观准）。
- ⚠️ 要先实测这个 RSS 在代理下是否 200（可能是 302 到 consent 页）。
